# Cost Planning Model

Hosting is not the main long-term cost. Engineering, content, safeguarding, moderation, support, training, security review, and maintenance dominate.

| Stage | Planning range per month |
|---|---:|
| Prototype with fictional data | $50–$150 |
| Public site + member MVP | $100–$400 |
| Active community, media, AI, notifications | $300–$1,000 |
| Multi-region/high-media operation | $1,000+ |

Track separately:

- Vercel team and usage
- Supabase compute, storage, egress, realtime, and backups
- transactional email and optional SMS
- monitoring and media backup storage
- Bible licensing/provider
- AI usage with hard budgets
- ChMS/Planning Center subscription
- domain/DNS
- advertising
- legal/privacy/security/accessibility review

Review actual costs monthly. Set provider budgets and alerts. Do not reduce retention or safety controls merely to hide cost.
