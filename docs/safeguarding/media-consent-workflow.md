# Child Media Consent Workflow

1. Guardian grants or denies each exact scope.
2. Upload is validated for type/size and stored privately.
3. Malware scan completes.
4. Image metadata/location is removed.
5. Subjects are identified without public facial-recognition indexing.
6. System verifies active consent for every child and requested scope.
7. Trained reviewer approves or rejects.
8. Private access uses short-lived authorization; public publication copies only the approved asset.
9. Guardian/member can submit takedown request.
10. Removal propagates to controlled channels and a manual external-platform checklist.
