# ADR: Require explicit source allowlists and human approval for AI

- Status: Accepted
- Date: 2026-08-02

## Decision

AI is useful for drafts and retrieval but cannot hold pastoral, safeguarding, publishing, role, or minor-contact authority. Citations and review state are stored with each request.

## Consequences

The implementation, tests, operational runbooks, and release gates must remain consistent with this decision. Reversal requires a new ADR that names migration, safety, cost, and ownership impacts.
