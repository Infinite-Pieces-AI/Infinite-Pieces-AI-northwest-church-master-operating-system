# ADR: Ship a mobile-first PWA before native applications

- Status: Accepted
- Date: 2026-08-02

## Decision

A PWA keeps one codebase, reduces release overhead, and tests actual member demand. Private responses are never cached. Native apps require a later usage and capability justification.

## Consequences

The implementation, tests, operational runbooks, and release gates must remain consistent with this decision. Reversal requires a new ADR that names migration, safety, cost, and ownership impacts.
