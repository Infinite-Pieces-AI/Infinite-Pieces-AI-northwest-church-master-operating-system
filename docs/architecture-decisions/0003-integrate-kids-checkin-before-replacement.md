# ADR: Integrate the existing child check-in system before considering replacement

- Status: Accepted
- Date: 2026-08-02

## Decision

Check-in and release are safety-critical and operationally mature in established ChMS products. The custom hub provides the guardian experience and mirrors status while the proven system remains authoritative.

## Consequences

The implementation, tests, operational runbooks, and release gates must remain consistent with this decision. Reversal requires a new ADR that names migration, safety, cost, and ownership impacts.
