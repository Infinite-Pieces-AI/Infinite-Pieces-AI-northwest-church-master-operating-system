# Group Rotation Workflow

- Clean active households, capacities, availability, leader assignments, and pairing history.
- Record hard constraints separately from private pastoral/safeguarding constraints.
- Generate deterministic proposal with approved seed and algorithm version.
- Review infeasibility, warnings, score, repeat pairings, and travel/balance.
- Make manual adjustments with reason and actor.
- Approve final run with MFA.
- Activate memberships/channels and notify only after approval.
- Preserve private reasons from ordinary member views.
