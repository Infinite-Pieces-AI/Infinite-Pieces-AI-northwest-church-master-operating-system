# Access Request and Invitation Workflow

1. Review voluntary request.
2. Verify person through an approved human relationship.
3. Select allowed roles and optional household.
4. Require MFA for approving leader.
5. Create hashed, single-use, email-bound invitation.
6. Send authenticated invite; revoke if delivery fails.
7. User accepts policies.
8. Database activates profile and roles atomically.
9. Review unconsumed/expired invitations and revoke as needed.
10. Remove access promptly when membership/volunteer status changes.
