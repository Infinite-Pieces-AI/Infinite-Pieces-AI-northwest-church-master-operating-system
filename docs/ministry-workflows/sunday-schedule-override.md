# Sunday Schedule Override Runbook

1. Authorized publisher confirms change with accountable minister.
2. Create date-specific override/replacement occurrence.
3. Enter plain public status message, location/time, parking/entrance changes.
4. Approve with MFA.
5. Verify homepage, Plan a Visit, hub, event page, JSON-LD, calendar, and notification draft.
6. Communications leader reviews social/email drafts.
7. After the date, archive or retain override according to policy; never erase audit history.
